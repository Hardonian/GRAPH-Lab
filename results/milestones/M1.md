# Milestone 1 — Exact graph engine

Date: 2026-10-16. Status: **PASS**.

## Delivered

Rust core (`crates/graphlab-core`):
- `graph.rs` — compact bitset undirected simple graph (n ≤ 64), typed
  rejection of self-loops / out-of-range / oversized inputs.
- `g6.rs` — strict graph6 codec. Cross-checked against the maintained
  `graph6` crate on **all 1,044,928 labeled graphs up to n=5** (round-trip
  + string equality) — 0 disagreements.
- `canon.rs` — two INDEPENDENT canonicalization backends:
  (a) exhaustive lex-max permutation canonical form (exact by construction,
      hard cap n≤8, refuses above),
  (b) nauty/Traces `getcanon` vendored via `nauty-pet` 0.15.0
      (`nauty-Traces-sys` 0.11.0, compiled from C sources pinned in Cargo.lock).
  Tests: bijection agreement on all 2^10 labeled graphs n=5; relabeling
  invariance ×50 random permutations at n=10 (nauty path); C6 vs 2·C3
  (same degree sequence, different classes) correctly distinguished.
- `enumerate.rs` — unlabeled enumeration n≤6 with canonical dedup; known
  counts verified.
- `invariants.rs` — exact components, triangles, C4 count, clique number,
  independence number, chromatic number (DFS coloring), exact rational
  density. All integer math.

Python control plane (`python/graphlab/`): independent pure-Python graph6
codec + networkx/igraph/DP oracles (`oracle.py`), strict mypy, pytest, ruff.
Chromatic oracle uses an independent-set-cover DP — a different algorithm
from the Rust DFS — so agreement is cross-algorithm evidence.

CLI: `graphlab doctor|hash|enumerate|invariants|canon|g6` all functional with
typed exit codes on failure (3=engine limit, 4=canon, 5=invalid g6,
6=round-trip mismatch).

## Scope statement (what EXACT_FINITE does NOT mean)

All verification covers n ≤ 6 simple undirected graphs. n ≥ 7 enumeration
uses the nauty backend above the exhaustive cap (canonicalization still
exact modulo nauty trust); no claim is made beyond n=6 coverage in this
milestone. `results/enumeration-v6.jsonl` (156 rows) is regenerable via
`graphlab enumerate --vertices 6`.
