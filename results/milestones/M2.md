## Discrepancies found & resolved during M2 (root-cause log)

1. **Hadwiger search bug (real, engine-level):** initial partition-based
   search required branch sets to cover ALL vertices, so K2+isolated vertex
   reported h=1. Hadwiger predicate then flagged 17 "counterexamples" on
   n≤5 — mathematically impossible (Hadwiger is a theorem for chi≤6).
   Root cause isolated by cross-engine enumeration, fixed to
   deletion-tolerant branch sets, regression test added
   (`hadwiger_ge_chi_all_unlabeled_n5` now passes over all 53 classes).
   This is the pipeline doing its job: an independent theorem check caught
   an engine bug before it could produce a false research claim.
2. Petersen expectation in a test was wrong (h=4 hand-written; truth is
   h=5 — contracting the 5 spokes gives K5). Engine was right; test fixed,
   value cross-verified with an independent Python branch-set search.
3. graph6 crate compatibility: crate encodes with byte = 63+value (not
   64+value); fixed both codec sides + tests now pin the crate as oracle.

## Scope statements (honest limits)

- `hadwiger-exhaustive-n6` rules out Hadwiger counterexamples EXACTLY for
  simple undirected graphs with at most 6 vertices. It says nothing about
  n≥7.
- `weak-hadwiger` sampled run found nothing on 20k draws; sampling finds
  nothing about universality. Labeled EXPERIMENTAL.
- Witness recheck trusts: strict g6 codec + fresh predicate evaluation +
  (for chi/h) the in-engine exact routines; the *independent* layer is
  scripts/verify_witness.py (separate implementation), run on every
  witness-producing campaign from now on.
