# Milestone 4 — HPC / CPU / GPU acceleration

Date: 2026-10-16. Status: **PASS** (documented-GPU-unsuitable branch,
with working CPU acceleration — permitted by commission §3/§M4).

## Delivered

- `graphlab benchmark --threads N --gpu-if-capable [--output file]`:
  three measured kernels (enumerate+invariants, labeled n=6 sweep, exact
  Hadwiger), raw JSON at `results/bench/cpu-baseline-48t.json`, thread
  scaling sweep at `results/bench/scaling-summary.json` (1/8/16/48).
- Occupancy gate: `--gpu-if-capable` probes per-card utilization via
  nvidia-smi before any GPU attempt; aborts above 10%. At benchmark time
  all three cards were momentarily 0% — and GPU work was STILL not launched
  because no CUDA kernel exists; the report says so plainly. Nothing claims
  GPU execution.
- CPU parallelism: campaign runner and benchmarks use a bounded rayon pool
  (host default 48 = 75% of 64 threads; clamped in `campaign.rs`).
- Scaling honesty: the enumerate+dedup stage shows 1.0× (sequential
  enumeration bound), labeled sweep 1.9× (generation dominates), Hadwiger
  6.0× — real numbers, real bottleneck attribution, in
  `docs/GPU_FINDINGS.md`.

## GPU verdict (summary; full empirical argument in docs/GPU_FINDINGS.md)

Current exact engine scope is n ≤ 10 bitset graphs at ~0.3 µs/graph CPU.
Kernel launch + host-device round trip is ~15–20 µs minimum: the GPU loses
before computing. Combinatorial early-exit search (branch sets, coloring
DFS, canonical dedup) is not a dense-linalg workload. **CPU is default and
correctness oracle; GPU acceleration is deferred until a heuristic
large-pool scoring workload exists, and no GPU result is claimed anywhere.**
No fabricated throughput/FLOPS/speedups.

## Known gaps (declared, not hidden)

1. Full checkpoint/resume of a partial campaign file state is not
   implemented; deterministic replay makes it cheap to redo bounded work.
   Listed for post-M6.
2. n≥7 unlabeled enumeration still requires a geng-style backend (engine
   uses canonical dedup only to n=6); M5 candidates are scoped accordingly.
3. numactl binding: host has 1 NUMA node — binding is a no-op here,
   documented rather than scripted theatrically.
